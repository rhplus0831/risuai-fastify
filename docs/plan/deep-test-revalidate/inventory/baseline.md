## Counting rules

- Count a test file once by repository-relative path. The tracked set contains 983 `*.test.ts`, 36 `*.spec.ts`, and three explicitly configured `*.runner.ts` files.
- Count individual registered test cases after parameterized tables and registration loops expand. Do not count `describe` blocks, assertions, fixtures, snapshots, hooks, helper files, or repeated coverage/CI invocations as additional tests.
- Include both performance gates, all six UI coverage files, and both isolated compatibility configurations. The baseline compatibility tests belong to this repository even though their imports target the prepared historical worktree. Do not inventory the historical application itself.
- Vitest JSON listing omits skipped cases. The six skipped registrations below were recovered using the Vitest collection API and included in the total. They are not six additional files.
- Playwright counts are discovered cases for the configured single Chromium project. Runtime `test.skip(...)` calls inside test bodies are not evaluated during listing; browser listed counts are not guaranteed execution counts.
- Environment-dependent registrations are a snapshot with optional measurement/profile flags unset. Enabling flags may change which cases execute. A zero in the extra-skipped column means no additional omitted registration was found, not proof that the test cannot skip at runtime.
- Build/typecheck/documentation/topology validators and compatibility artifact comparisons are checks, not separately registered test cases. Their own unit-test files are included where discovered.
